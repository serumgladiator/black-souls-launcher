# Black Souls Launcher

Небольшое окно, из которого запускаются обе части Black Souls.

Лаунчер сам ищет файлы игры: Steam, ярлыки, документы, загрузки и папки вроде `Games`. Если ничего не нашёл, путь можно выбрать кнопкой «Путь» или просто перетащить `exe` в окно. Выбранные пути запоминаются.

Скачать готовый файл: [версия 1.1](https://github.com/serumgladiator/black-souls-launcher/releases/tag/v1.1).

## Как пользоваться

Сначала выбирается часть, потом разрешение, и только после этого «Запуск».

Стрелки вверх и вниз переключают часть, влево и вправо — размер окна. Клавиши 1 и 2 тоже выбирают часть. Enter запускает то, что выбрано.

- **Запуск** открывает выбранную часть в выбранном разрешении и закрывает лаунчер.
- **Путь** указывает файл запуска вручную.
- **Поиск** смотрит диски глубже. Повторное нажатие останавливает поиск.

Разрешения идут от родных 640×480 до окна на весь экран. Картинка остаётся 4:3, без растягивания вширь.

Окно можно перетащить за пустое место. Esc его закрывает.

Нужна Windows. Отдельно ничего ставить не надо: используется .NET Framework, который уже есть в системе.

## Сборка

Исходники — это `Launcher.cs` и `MenuForm.cs`. Собрать можно так:

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /optimize+ /target:winexe /out:BlackSoulsLauncher.exe /r:System.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll Launcher.cs MenuForm.cs
```
